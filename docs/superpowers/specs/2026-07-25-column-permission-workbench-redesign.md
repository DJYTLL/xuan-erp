# 列权限工作台改版设计

## 背景

当前 [frontend/src/views/IamColumnPermissionManagementView.vue](/abs/path/not-real) 仍然是“模板列表 + 规则弹窗”的旧交互。用户已确认新的工作台方向：

1. 左侧展示完整导航菜单树。
2. 不可配置页面保留，但以弱化样式展示。
3. 右侧改为上下结构：上半区字段配置器，下半区真实页面预览。
4. 页面级说明不再单独占用一整块大区域，而是压缩进字段配置器头部。

## 约束

- 当前后端接口仍是 `模板 + resourceKey + template items` 模式。
- 本轮不改后端协议，不新增迁移。
- 前端需要把“页面”概念桥接到现有 `resourceKey`，先通过本地映射配置兼容。

## 方案

### 1. 页面映射桥接

新增前端配置，把 `menuCode` 映射到一个或多个 `resourceKey`，并提供预览所需的静态示例数据。

首批仅接入：

- `tenant-management` -> `tenant`

其余页面先在菜单树中展示，但显示为不可配置状态。

### 2. 新工作台结构

列权限页面改成三段：

1. 顶部查询区：租户、模板选择、页面搜索、刷新/模板管理动作。
2. 左侧菜单树：使用现有 `NavigationMenuTree`。
3. 右侧工作区：
   - 头部轻量信息条：页名、菜单编码、路径、接入状态、显示数量。
   - 字段配置器：紧凑卡片布局，支持批量动作和字段开关。
   - 页面真实预览：基于当前模板规则展示最终列效果。

### 3. 规则兼容策略

字段卡片只暴露“显示/隐藏”切换，但内部仍保留后端的三态规则：

- `VISIBLE`
- `MASKED`
- `HIDDEN`

具体行为：

- 关闭字段 -> `HIDDEN`
- 重新打开字段 -> 优先恢复该字段原始可见模式；若没有原始模式且字段支持脱敏，则回到 `MASKED`，否则回到 `VISIBLE`
- “全部显示” -> 恢复当前页所有字段的首选可见模式
- “隐藏敏感字段” -> 当前页所有有 `maskType` 的字段切到 `HIDDEN`
- “恢复默认” -> 回到模板加载时的原始规则

### 4. 真实预览

真实预览只展示当前已接入列权限的字段，并根据规则实时反映：

- `VISIBLE`：显示原值
- `MASKED`：显示脱敏值
- `HIDDEN`：整列不渲染

## 落地文件

- 更新 `verify-column-permission-management.mjs`，改为验证新工作台结构

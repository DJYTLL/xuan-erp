本文记录 `xuan-procurement` 的数据库结构、表字段、普通索引、初始化数据和 Flyway migration 对应关系。

## 数据库归属

| 项 | 内容 |
| --- | --- |
| 数据库 | `xuan_procurement` |
| migration 目录 | `xuan-procurement/src/main/resources/db/migration/` |
| 当前 migration 最新版本 | `V1` |
| 本次新增 migration | `V1__init_procurement_database.sql` |
| 数据所有权 | 只允许 `xuan-procurement` 直接写入采购单和采购退货 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_procurement`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 采购单保存供应商、商品、仓库、库位快照字段，审核后通过事件驱动库存和财务。

- 应用层校验 `status IN ('DRAFT','APPROVING','APPROVE_FAILED','APPROVED','CANCELLED','RED_FLUSHED')`。

- 应用层校验 `total_amount >= 0`。
- 应用层校验 `total_amount_excl_tax >= 0`。
- 应用层校验 `total_tax_amount >= 0`。
- 应用层校验 `total_amount_incl_tax >= 0`。
- 应用层校验 `version >= 0`。
- 应用层校验 `print_count >= 0`。
- 应用层校验 `total_amount_excl_tax + total_tax_amount = total_amount_incl_tax`。
- 应用层校验 `paid_amount >= 0`。
- 应用层校验 `discount_amount >= 0`。
- 应用层校验 `paid_amount + discount_amount <= total_amount`。

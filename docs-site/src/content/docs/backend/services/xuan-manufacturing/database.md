| 项 | 内容 |
| --- | --- |

| 本次新增 migration | `V1__init_manufacturing_database.sql` |
| 数据所有权 | 只允许 `xuan-manufacturing` 直接写入组装/拆分模板和组装/拆分单据 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_manufacturing`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 商品、仓库、库位只保存外部 ID 和快照字段，不建跨服务外键。

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_assembly_template` | `id` | primary | 主键 |
| `idx_manufacturing_template_code_active` | `tenant_id, code; WHERE deleted_at IS NULL` | normal | 模板编码活动态唯一；唯一性由应用逻辑保证 |
| `idx_manufacturing_template_tenant_deleted` | `tenant_id, deleted_at` | normal | 租户活动数据过滤；唯一性由应用逻辑保证 |

### 逻辑约束

- 应用层校验 `template_type IN ('ASSEMBLY','DISASSEMBLY')`。
- 应用层校验 `qty >= 0`。

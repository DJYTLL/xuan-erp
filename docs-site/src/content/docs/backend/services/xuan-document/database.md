本文记录 `xuan-document` 的数据库结构、表字段、普通索引、初始化数据和 Flyway migration 对应关系。

## 数据库归属

| 项 | 内容 |
| --- | --- |
| 数据库 | `xuan_document` |
| migration 目录 | `xuan-document/src/main/resources/db/migration/` |
| 当前 migration 最新版本 | `V1` |
| 本次新增 migration | `V1__init_document_database.sql` |
| 数据所有权 | 只允许 `xuan-document` 直接写入打印模板、打印日志和打印快照 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_document`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 业务表默认包含 `tenant_id`，平台级或网关级表会在表说明中单独说明。
- 逻辑删除统一使用 `deleted_at`，活动态唯一性由应用层在 `deleted_at IS NULL` 范围内校验。

| 表名 | 说明 | 是否包含 tenant_id |
| --- | --- | --- |

## `print_template`

打印模板配置表。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint GENERATED BY DEFAULT AS IDENTITY` | 是 | `` | 主键 |
| `tenant_id` | `bigint` | 是 | `` | 租户 ID，来源于 xuan-tenant |
| `code` | `varchar(64)` | 是 | `` | 模板编码 |
| `name` | `varchar(100)` | 是 | `` | 模板名称 |
| `doc_type` | `varchar(50)` | 是 | `` | 单据类型 |
| `header_title` | `varchar(120)` | 否 | `` | 标题 |
| `sub_title` | `varchar(120)` | 否 | `` | 副标题 |
| `footer_note` | `varchar(500)` | 否 | `` | 页脚备注 |
| `field_config` | `jsonb` | 否 | `` | 字段配置 |
| `sort_no` | `integer` | 是 | `0` | 排序 |
| `is_default` | `boolean` | 是 | `false` | 是否默认 |
| `is_enabled` | `boolean` | 是 | `true` | 是否启用 |
| `remark` | `varchar(500)` | 否 | `` | 备注 |
| `created_by` | `varchar(100)` | 否 | `` | 创建人 |
| `created_at` | `timestamptz` | 是 | `now()` | 创建时间 |
| `updated_by` | `varchar(100)` | 否 | `` | 更新人 |
| `updated_at` | `timestamptz` | 是 | `now()` | 更新时间 |
| `deleted_by` | `varchar(100)` | 否 | `` | 删除人 |
| `delete_reason` | `varchar(500)` | 否 | `` | 删除原因 |
| `deleted_at` | `timestamptz` | 否 | `` | 逻辑删除时间 |

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_print_template` | `id` | primary | 主键 |
| `idx_document_template_code_active` | `tenant_id, code; WHERE deleted_at IS NULL` | normal | 模板编码活动态唯一；唯一性由应用逻辑保证 |
| `idx_document_template_default` | `tenant_id, doc_type; WHERE is_default = true AND deleted_at IS NULL` | normal | 每单据类型一个默认模板；唯一性由应用逻辑保证 |
| `idx_document_template_doc` | `tenant_id, doc_type, is_enabled, sort_no` | normal | 单据类型模板查询；唯一性由应用逻辑保证 |

### 逻辑约束

- 应用层校验 `sort_no >= 0`。

## `undo_log`

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `branch_id` | `bigint` | 是 | `` | Seata 分支事务 ID |
| `xid` | `varchar(128)` | 是 | `` | Seata 全局事务 ID |
| `context` | `varchar(128)` | 是 | `` | 上下文 |
| `rollback_info` | `bytea` | 是 | `` | 回滚信息 |
| `log_status` | `integer` | 是 | `` | 日志状态 |
| `log_created` | `timestamp(6)` | 是 | `` | 创建时间 |
| `log_modified` | `timestamp(6)` | 是 | `` | 更新时间 |

### 主键与普通索引

| --- | --- | --- | --- |

| `idx_undo_log_log_created` | `log_created` | normal | 按创建时间清理和排查回滚日志 |

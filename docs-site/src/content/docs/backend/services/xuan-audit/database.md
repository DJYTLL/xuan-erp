本文记录 `xuan-audit` 的数据库结构、表字段、普通索引、初始化数据和 Flyway migration 对应关系。

## 数据库归属

| 项 | 内容 |
| --- | --- |
| 数据库 | `xuan_audit` |
| migration 目录 | `xuan-audit/src/main/resources/db/migration/` |
| 当前 migration 最新版本 | `V1` |
| 本次新增 migration | `V1__init_audit_database.sql` |
| 数据所有权 | 只允许 `xuan-audit` 直接写入审计日志、SQL trace 和平台幂等记录 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_audit`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 审计、SQL trace 和幂等记录属于追加型或运维型数据，不参与业务恢复模型。
- 后续如果服务级幂等需要下沉到业务服务，可通过新增 migration 拆分。

## `audit_log`

审计日志表，记录用户动作、请求信息和跨租户访问痕迹。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint GENERATED BY DEFAULT AS IDENTITY` | 是 | `` | 主键 |
| `tenant_id` | `bigint` | 是 | `` | 租户 ID，来源于 xuan-tenant |
| `actor_username` | `varchar(100)` | 否 | `` | 操作者用户名 |
| `actor_user_id` | `bigint` | 否 | `` | 操作者用户 ID |
| `action` | `varchar(100)` | 是 | `` | 动作标识 |
| `entity_type` | `varchar(100)` | 是 | `` | 实体类型 |
| `entity_id` | `varchar(64)` | 否 | `` | 实体 ID |
| `detail` | `text` | 否 | `` | 详情 |
| `status` | `varchar(20)` | 是 | `'SUCCESS'` | 结果状态 |
| `request_id` | `varchar(64)` | 否 | `` | 请求 ID |
| `client_ip` | `varchar(64)` | 否 | `` | 客户端 IP |
| `user_agent` | `varchar(400)` | 否 | `` | 客户端 UA |
| `duration_ms` | `bigint` | 否 | `` | 耗时毫秒 |
| `method` | `varchar(16)` | 否 | `` | 请求方法 |
| `path` | `varchar(500)` | 否 | `` | 请求路径 |
| `http_status` | `integer` | 否 | `` | HTTP 状态 |
| `error_code` | `varchar(64)` | 否 | `` | 错误码 |
| `error_message` | `varchar(500)` | 否 | `` | 错误信息 |
| `auth_tenant_id` | `bigint` | 否 | `` | 认证租户 ID |
| `auth_tenant_code` | `varchar(100)` | 否 | `` | 认证租户编码 |
| `is_cross_tenant` | `boolean` | 是 | `false` | 是否跨租户 |
| `created_at` | `timestamptz` | 是 | `now()` | 创建时间 |

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_audit_log` | `id` | primary | 主键 |
| `idx_audit_log_tenant_actor` | `tenant_id, actor_username, created_at DESC` | normal | 租户操作者审计查询；唯一性由应用逻辑保证 |
| `idx_audit_log_request` | `request_id` | normal | 按请求 ID 查询；唯一性由应用逻辑保证 |
| `idx_audit_log_path` | `path` | normal | 按请求路径查询；唯一性由应用逻辑保证 |

### 逻辑约束

- 应用层校验 `status IN ('SUCCESS','FAILURE')`。
- 应用层校验 `duration_ms IS NULL OR duration_ms >= 0`。
- 应用层校验 `http_status IS NULL OR http_status BETWEEN 100 AND 599`。

## `sql_request_trace`

一次请求级 SQL 汇总。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint GENERATED BY DEFAULT AS IDENTITY` | 是 | `` | 主键 |
| `tenant_id` | `bigint` | 是 | `` | 租户 ID，来源于 xuan-tenant |
| `request_id` | `varchar(64)` | 是 | `` | 请求 ID |
| `request_path` | `varchar(500)` | 是 | `` | 请求路径 |
| `request_method` | `varchar(16)` | 是 | `` | 请求方法 |
| `response_status` | `integer` | 否 | `` | 响应状态 |
| `request_cost_ms` | `bigint` | 是 | `0` | 请求耗时 |
| `sql_total_cost_ms` | `bigint` | 是 | `0` | SQL 总耗时 |
| `sql_count` | `integer` | 是 | `0` | SQL 数量 |
| `started_at` | `timestamptz` | 是 | `` | 开始时间 |
| `finished_at` | `timestamptz` | 是 | `` | 结束时间 |
| `username` | `varchar(100)` | 否 | `` | 用户名 |
| `user_id` | `bigint` | 否 | `` | 用户 ID |
| `created_at` | `timestamptz` | 是 | `now()` | 创建时间 |

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_sql_request_trace` | `id` | primary | 主键 |
| `idx_audit_sql_request` | `tenant_id, request_id` | normal | 请求 trace 唯一；唯一性由应用逻辑保证 |
| `idx_audit_sql_request_cost` | `tenant_id, sql_total_cost_ms DESC, created_at DESC` | normal | 慢 SQL 请求排序；唯一性由应用逻辑保证 |

### 逻辑约束

- 应用层校验 `finished_at >= started_at`。
- 应用层校验 `request_cost_ms >= 0`。
- 应用层校验 `sql_total_cost_ms >= 0`。
- 应用层校验 `sql_count >= 0`。
- 应用层校验 `response_status IS NULL OR response_status BETWEEN 100 AND 599`。

| `created_at` | `timestamptz` | 是 | `now()` | 创建时间 |

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_sql_trace_entry` | `id` | primary | 主键 |
| `idx_audit_sql_entry_sequence` | `request_trace_id, sequence_no` | normal | 同一请求 SQL 序号唯一；唯一性由应用逻辑保证 |
| `idx_audit_sql_entry_cost` | `tenant_id, cost_ms DESC, executed_at DESC` | normal | 慢 SQL 明细排序；唯一性由应用逻辑保证 |

### 逻辑约束

- 应用层校验 `request_trace_id` 必须引用有效的 `sql_request_trace.id`。
- 应用层校验 `sequence_no >= 1`。
- 应用层校验 `cost_ms >= 0`。

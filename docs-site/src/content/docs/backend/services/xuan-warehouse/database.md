| 项 | 内容 |
| --- | --- |
| 数据库 | `xuan_warehouse` |
| migration 目录 | `xuan-warehouse/src/main/resources/db/migration/` |
| 当前 migration 最新版本 | `V1` |
| 本次新增 migration | `V1__init_warehouse_database.sql` |
| 数据所有权 | 只允许 `xuan-warehouse` 直接写入仓库和库位基础档案 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_warehouse`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 业务表默认包含 `tenant_id`，平台级或网关级表会在表说明中单独说明。
- 逻辑删除统一使用 `deleted_at`，活动态唯一性由应用层在 `deleted_at IS NULL` 范围内校验。

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_warehouse` | `id` | primary | 主键 |
| `idx_warehouse_warehouse_code_active` | `tenant_id, code; WHERE deleted_at IS NULL` | normal | 仓库编码活动态唯一；唯一性由应用逻辑保证 |
| `idx_warehouse_default` | `tenant_id; WHERE is_default = true AND deleted_at IS NULL` | normal | 每租户一个默认仓库；唯一性由应用逻辑保证 |

| `idx_warehouse_warehouse_tenant_deleted` | `tenant_id, deleted_at` | normal | 租户活动数据过滤；唯一性由应用逻辑保证 |

## `undo_log`

Seata AT 模式回滚日志表，用于全局事务回滚。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `branch_id` | `bigint` | 是 | `` | Seata 分支事务 ID |
| `xid` | `varchar(128)` | 是 | `` | Seata 全局事务 ID |
| `context` | `varchar(128)` | 是 | `` | 上下文 |
| `rollback_info` | `bytea` | 是 | `` | 回滚信息 |
| `log_status` | `integer` | 是 | `` | 日志状态 |
| `log_created` | `timestamp(6)` | 是 | `` | 创建时间 |
| `log_modified` | `timestamp(6)` | 是 | `` | 更新时间 |

### 主键与普通索引

| 名称 | 字段/表达式 | 类型 | 说明 |
| --- | --- | --- | --- |
| `pk_undo_log` | `branch_id, xid` | primary | 主键 |
| `idx_undo_log_log_created` | `log_created` | normal | 按创建时间清理和排查回滚日志 |

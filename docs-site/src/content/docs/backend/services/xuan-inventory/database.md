## 数据库归属

| 项 | 内容 |
| --- | --- |
| 数据库 | `xuan_inventory` |
| migration 目录 | `xuan-inventory/src/main/resources/db/migration/` |
| 当前 migration 最新版本 | `V1` |
| 本次新增 migration | `V1__init_inventory_database.sql` |
| 数据所有权 | 只允许 `xuan-inventory` 直接写入库存余额、流水、盘点、移库、库存占用和库存策略 |

## migration 规则

涉及数据库结构、字段、索引、约束、初始化数据或 Flyway 脚本时，必须先扫描本服务 `db/migration` 目录，确认当前最高版本号，再追加新 migration。禁止跳号、复用版本号、修改历史 migration。

本次扫描结果：本服务历史最高版本为“无”，新增 `V1`，不存在版本冲突。

## 设计说明

- 本服务使用独立数据库 `xuan_inventory`，服务启动时 Flyway 连接该数据库执行 migration。
- migration 只管理当前连接数据库内的表、索引、约束和初始化数据；不包含 `CREATE DATABASE`，也不创建 PostgreSQL schema。
- 跨服务只保存外部 ID、编码和必要快照字段，不建立跨服务数据库外键。
- 数据库只保留表结构、主键和普通查询索引；外键、唯一性、状态枚举、金额非负等业务约束全部由应用逻辑校验。
- 业务表默认包含 `tenant_id`，平台级或网关级表会在表说明中单独说明。
- 逻辑删除统一使用 `deleted_at`，活动态唯一性由应用层在 `deleted_at IS NULL` 范围内校验。

- 应用层校验 `max_stock IS NULL OR max_stock >= 0`。

### 跨服务引用

- `product_id` 引用 `xuan-product.product.id`，`warehouse_id` 引用 `xuan-warehouse.warehouse.id`，均不建数据库外键。
